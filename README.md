# 要穴かるた（五兪穴）

一つの経絡の井・栄・兪・経・合、五枚だけを並べて取る読み上げかるた。iPad縦画面向け。

- 1人：タイムアタック（自己ベストを端末に保存）／CPU戦（やさしい・ふつう・つよい）
- 2人：iPadを挟んで向かい合わせで対戦
- 一度に並べる経絡：1経（5枚）・2経（10枚）・3経（15枚）。場に1枚残ったらその札は読まずに次へ
- 読み札：大会や市販の『経穴かるた』と同じ「手の太陰肺経（一呼吸）井木穴」。ほかに五兪だけ・五行だけ・ミックス。文字は取るまで出さない

公開ページ: https://lionemikosan-sketch.github.io/yoketsu-karuta-goyu/

`karuta.html` を編集したら `./build.sh` で `index.html` を作り直す。
